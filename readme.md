## 📌 About This Repository

Welcome to my Software Systems Engineering Laboratory Portfolio for ENSE271 course.

This repository showcases the practical work completed throughout the course in the lab. It serves as a structured record of six laboratory assignments, including project documentation, implementation work, screenshots, and supporting resources.

The purpose of this portfolio is to demonstrate the practical application of course concepts, document the development process, and reflect on the knowledge and skills gained through each laboratory exercise.

## 🎯 Portfolio Objectives

- Apply theoretical concepts through practical lab assignments.
- Develop technical and problem-solving skills.
- Document the process and outcomes of each experiment.
- Maintain organized and accessible project documentation.
- Demonstrate learning progression throughout the course.
